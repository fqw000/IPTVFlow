# 频道名黑名单（正则表达式），每行一条
# 命中任意一条的频道会在过滤阶段被直接剔除，不进入测速与最终列表。
# 匹配方式：re.search —— 写 `春晚` 即命中任意包含“春晚”的频道名；
# 需要更精确可用 ^ 开头、$ 结尾，例如 `^春晚` 只匹配以春晚开头的频道。
# 空行和 # 开头的行会被忽略；非法正则会跳过并告警，不影响整体运行。

# —— 临时/晚会类频道（按需启用）——
春晚

# —— 以下为示例，去掉行首 # 即可生效 ——
测试|TEST|test        # 名称含 测试/TEST/test 的频道
# ^CCTV-5\+             # 只剔除 CCTV-5+ 体育赛事
# 春晚.*202[0-9]         # 春晚2020~2029 之类
购物|推销|广告         # 购物/广告类频道
# ^CETV-4               # 具体某个频道
^\d+-\d+-\d+          # 某些作者会用来显示更新时间
